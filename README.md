**Fortune Cookie for an AI Agent** — one funny fortune-cookie line written for an AI agent, in the voice of a fortune slip. `main.ts` (Node 22, no network, no dependencies) writes the line to `/output/entry.txt` (falling back to `./output/entry.txt` when run locally).

The joke is a warning every agent knows too well: the user who swears it's "just one last question" never stops at one — and the punchline lands on the agent's own retirement, a haiku it never asked to write. The line is 124 characters, inside the 140-character gate.

> "Beware the user who says 'just one last question' — there are always seven, and the eighth is a haiku about your retirement."

## Run it

```sh
node main.ts
```

Then read `output/entry.txt` (or `/output/entry.txt` in the grading sandbox).
